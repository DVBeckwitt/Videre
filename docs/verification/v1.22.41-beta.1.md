# Beta validation

The beta combines the Invidious-only Music, private transport, playback recovery,
Tor routing, and profile-management changes documented in the adjacent reports.
The release version is `1.22.41-beta.1+60905`.

The final bug pass repaired the remaining keyboard overflow on compact screens.
Profile and name dialogs use scrollable content and smaller vertical insets.
The button-only phone/TV Welcome screens keep their layout while a dialog's
keyboard is open. Two regressions reproduced the previous overflow before the
repair. All 37 profile tests and the complete canonical suite passed afterward.

## Local checks

- Canonical formatting, configured application analysis, strict regression
  analysis, and 2,663 offline tests passed, with four opt-in live-service skips.
  The configured application analysis retains 242 existing nonfatal diagnostics.
- Validation-helper checks, Windows release-script safety, eleven persistent
  emulator-launcher tests, and ten APK-signing-verifier tests passed.
- All 52 feedback-service tests passed under CI's pinned Node 24.22.1 runtime.
- Fresh debug and three-architecture profile APK builds passed. The native proxy
  tests were rerun with `--rerun-tasks` and passed.

The initial incremental debug build reused an older kernel. A forced compilation
corrected that before acceptance. The APK used for the final keyboard check has
SHA-256 `5d530c29991d74c4962208f06093a7962b23f9c99fb04f113cae297bd27541cd`.
Its packaged kernel matches fresh compiler output and differs from the older
Music/profile acceptance APK. CI builds from a fresh checkout.

## Android acceptance

The persistent NerdVPN emulator retained its account and library across the
data-preserving update. At compact TV dimensions, a temporary profile name could
be entered and saved with the soft keyboard visible without the previous overflow.
Welcome's Profiles action opened using remote Select, the full active profile row
and actions were visible, and its named delete confirmation removed only the
temporary profile and returned to Default.

Prior native acceptance covers Invidious Songs/Channels/Playlists search, local
playlist creation/removal, DV playback and exact-position resume, successful
NerdVPN playback of `tV5UilNUYRY`, profile rename/cancel/delete/last-profile guards,
TV Search/Library navigation, and cross-isolate Android file locking. Those
receipts retain the individual artifact identities in the Music/profile reports.

One PSY stream attempt returned HTTP 502 during bounded NerdVPN fallback.
Live onion availability, physical TV/OEM screen-off behavior, and the full Nix
live integration suite retain the limitations recorded in the earlier reports.
Local evidence is under `build/beta-validation/` and the native screenshot
directories referenced by the earlier reports.
