# Beta 2 regression and release checks

Version: `1.22.46-beta.2+60917`. This pass integrates local Takeout import,
RSS podcasts and resume positions, and the issue #38 investigation.

## Local gates

- Pinned Flutter 3.35.3 / Dart 3.9.2 canonical validation: 3,163 tests passed,
  six optional live-service tests skipped. Formatting checked 711 files without
  changes. Strict regression analysis passed; application analysis retained
  four existing warnings and 236 informational diagnostics, with no errors.
- Validation-helper tests: five passed.
- Native JVM tests: 121 proxy and 15 application tests passed.
- Isolated Android proxy suite: 32 passed, two opt-in Orbot checks skipped.
- Windows release helper: 14 checks passed. APK signing verifier: 10 tests passed.
- Feedback service on Node 24.22.1: 52 tests passed.
- Final x86_64 profile APK built successfully with JDK 21: 70,151,225 bytes,
  SHA-256 `09d4beea7324100e99ed83778b9b2931441ab7a38eb79e3c2483cce9ffe828d5`.

Independent source reviews covered profile isolation, import cancellation,
podcast transport/download/storage boundaries, credential rollback, release
packaging, and asynchronous sign-in cleanup. A Takeout cancellation regression
was repaired: a late file-picker result can no longer pop the underlying page
after the dialog closes. Both Cancel and Android Back have focused regression
coverage.

## Android evidence and limits

The persistent signed-in `Videre_NerdVPN_Test` AVD retained its existing accounts
and data. Final APK acceptance verified clean cancellation from both a fresh
NerdVPN draft and existing-account reauthentication, preserved API access,
saved-account video playback and seeking, and the visible manual-key fallback.
See [NerdVPN investigation](issue-38-nerdvpn.md) for measurements and remaining
fresh-credential coverage limits.

Earlier feature builds established local-only Takeout import with network
disabled and native podcast streaming, downloads, background playback, and
resume across offline process restarts. Their precise artifacts and evidence
are recorded in [Takeout checks](takeout-import.md) and
[podcast checks](podcasts.md). Final automated gates cover the integrated source.

Nadeko's tested proxied streams still return `403 Endpoint disabled`; see the
[Nadeko investigation](issue-38-nadeko.md). No direct YouTube/Google fallback was
added. Physical phone/TV, ARM runtime, and the full live Invidious suite were not
run locally. Hosted Linux build and release checks must pass for the exact
commit before this beta is considered published and verified.
