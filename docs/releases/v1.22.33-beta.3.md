# Videre 1.22.33 Beta 3

This is an opt-in beta prerelease. The latest stable release remains v1.22.32.

## New in Beta 3

- **Customizable phone navigation:** open the Home pencil → Navigation, or Settings → Browsing → Customize app sections. Touch and hold an item to reorder it or move it between Bottom tabs, Top icons, and Hidden. Tap an item for move controls or to choose a main screen tab to open at startup. Changes save automatically.
- Keep between two and five bottom items, including at least one main screen tab. Settings always stays available, and extra top icons are accessible from the overflow menu.
- Restore default navigation at any time: Home, Subscriptions, History, Search below; Downloads, Queue, Playlists above. Existing custom sections and startup preferences are retained when migrating to the new editor. Phone changes do not replace tablet or TV layouts.
- Navigation preferences are included in library backups. Search keeps its focused field and keyboard behavior wherever its shortcut is placed.

## Fixes

- Dropping an item back onto itself leaves its position unchanged.
- Dragging near the screen edge keeps scrolling while held, and releasing uses the item or area currently under your finger.
- Failed saves preserve the previous layout and allow retry; removing the selected tab falls back to a usable screen.
- Home-content controls fit narrow phones and scroll in landscape.
- Long shortcut names wrap in the top overflow menu at large text sizes.

All Beta 2 features remain included: the queue shortcut, remembered video quality, configurable download folder, optional hiding of watched subscription videos, and seek previews.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the existing Videre package and release signing identity. Export a library backup before trying it; returning to an older stable version may require reinstalling.

Regression coverage includes saved layouts, migration, backups, startup selection, search focus, cross-area dragging, edge scrolling, save failure, and narrow/landscape editors. Native touch checks use an Android phone emulator. Physical phones, physical TVs, and live Invidious integration tests are not covered by these checks. A pre-existing video-card overflow with large text on very narrow screens remains outside this navigation update.

The release workflow verifies APK versions and the existing signing identity. `SHA256SUMS` covers the attached APKs, bundles, and source archives.
