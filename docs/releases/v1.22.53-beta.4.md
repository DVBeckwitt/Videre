# Videre 1.22.53 Beta 4

- **Downloads.** Downloads check available space for temporary files and the
  destination where Android can measure it. You can check space again after
  freeing room. Eligible downloads retain compatible partial files and resume
  when the connection returns.
- **Offline Video Home.** When For You or Discover is empty offline, Home shows
  readable video downloads from your active profile. When the connection
  returns, you can refresh whenever you're ready.
- **Liked Songs.** Open Liked Songs directly from Music Home. If you use a
  custom layout, you can add the shortcut in **Customize Music layout**.
- **Saved Music playlists.** Reopened playlists can show their last complete
  track list right away. Videre refreshes it when stale or when you tap Refresh.
- **Watch.** With Return YouTube Dislike enabled, Watch can show a labeled like
  estimate when your selected instance leaves out the count.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60967** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
