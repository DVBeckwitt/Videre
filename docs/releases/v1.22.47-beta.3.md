# Videre 1.22.47 Beta 3

Matching video thumbnails, channel search results, and Music discovery cards
now show an amber **AI** badge. Tap it on a phone or tablet to see which list
flagged the channel and choose **Allow this channel**.

Install **app-arm64-v8a-release.apk** for most modern Android devices, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Build **60921** uses the existing package and signing identity. `SHA256SUMS`
lists the checksums for the release assets.
