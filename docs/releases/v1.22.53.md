# Videre 1.22.53

- **Music discovery.** Filter searches by song, album, artist, or playlist.
  Open verified artist matches as they appear, search within an artist's
  catalog, and use optional voice search. In Music Home, open Liked Songs and
  see verified Starter artists suggestions as they arrive.
- **Local music and playlists.** Browse folders and downloads together, jump
  through artist and genre indexes, and queue an entire artist or genre.
  Select multiple songs, organize playlists into folders, and choose how M3U
  exports write file paths. Saved playlists can reopen from their last complete
  track list while Videre refreshes it.
- **Music playback.** Open Queue, Sleep, and Lyrics from the Now Playing footer.
  Sort upcoming tracks, start radio while the current song plays, and like
  tracks from the mini-player or Android media controls. If a downloaded copy
  fails to open, Videre can try the selected server. Lyrics can fall back to
  a song and artist search when the exact lookup misses.
- **Video Home and Watch.** Empty For You and Discover feeds can show playable
  downloads when offline. Watch adds a fullscreen touch lock, pinch to zoom,
  chapter gestures, and seek previews. With Return YouTube Dislike enabled,
  Watch can show a labeled like estimate when the selected instance omits it.
- **Downloads.** Videre checks available space for temporary and destination
  files where Android can report it. Eligible downloads keep compatible partial
  files and resume when the connection returns.
- **Public instances.** ChocolateMoo joins NerdVPN and DVBeckwitt in server
  setup. You can review its separate playback hosts individually. Videre can
  retry eligible playback failures on another backend.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60968** updates the 1.22.53 betas and uses the existing Videre package
and signing key. **SHA256SUMS** lists the release file checksums.
