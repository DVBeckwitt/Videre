# Videre 1.22.54 Beta 1

- **Music Now Playing.** Swipe down from the artwork or the top of the
  Now Playing screen to dock it in the mini-player. Keep browsing while the
  same song plays, and tap the mini-player to reopen Now Playing.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60969** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
