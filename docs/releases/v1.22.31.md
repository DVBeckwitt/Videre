# Videre 1.22.31

This update gives you more control over playback and makes it easier to send feedback.

- Adjust playback speed with quick presets or the slider, and change pitch separately. Your speed now stays put when you switch between video and audio.
- Pick a backend from the player on supported instances. Automatic fallback is on by default for new backend setups, tries another backend when playback fails, and keeps the working one when you switch modes. You can turn it off in settings; existing choices are kept.
- Open Transcript right beside Playback speed below the video. Back closes the transcript, speed sheet, or backend picker before minimizing the player.
- Send bug reports and suggestions from the app without a GitHub account. Screenshots and diagnostics are optional, and you can review everything before sending. If sending fails, your draft stays available for another try.

SponsorBlock sponsor skipping and Return YouTube Dislike counts stay on by default. Shared YouTube links now open in the right TV screen. We also fixed early TV seeking, pause and seek timing issues, stale requests after connection changes, login state updates, and feedback text validation. Duplicate player helpers and unused code have been cleaned up without removing features.

Install **app-release.apk** for the universal build, or choose the smaller APK for your device. Android 7.0 or newer is required. This release uses the usual Videre package and signing identity, so it updates an existing official installation.

Checked with automated tests and an Android emulator, including the TV interface. Physical TV behavior, live Orbot feedback delivery, and real feedback issue creation are still unverified. Public-instance availability can vary; a requested backend is not proof of the server's internal routing.

`SHA256SUMS` covers the attached APKs, bundles, and source archives.
