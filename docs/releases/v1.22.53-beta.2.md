# Videre 1.22.53 Beta 2

- **Faster artist search.** The Artists filter displays confirmed matches as they
  arrive. You can open an artist while the remaining checks run, and confirmed
  matches stay available if a later check fails.
- **Video search.** Phone and TV searches can load more results when local
  filters hide the current page. TV section headings follow the active search.
- **Android links and shortcuts.** When several supported open requests arrive
  close together, the most recent one takes priority.
- **Watch playback.** Two-finger chapter skips require two taps close together.
- **Music playback.** If an optional downloaded copy fails to open, Videre tries
  the selected server while the current song keeps playing.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60965** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
