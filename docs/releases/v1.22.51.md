# Videre 1.22.51

Some Invidious instances load comments and video details from one server but
stream the video from another. Videre can now play from those separate HTTPS
hosts on Android. The advanced server setup check shows the hosts it finds
and lets you choose which to allow. Videre remembers your choice, including
skipping all hosts, for that instance in your profile.

For an existing account, open **Settings → Manage servers**, select the
account, then open **Media companion hosts**. Enter the exact HTTPS address
provided by the instance operator. Videre keeps your login on the selected
instance. [Android playback verification](https://github.com/DVBeckwitt/Videre/blob/v1.22.51/docs/verification/chocolatemoo53-eu.md#issue-48-playback-check)

- **Playback and downloads.** With automatic fallback enabled, Videre can try
  up to two other backends on the same account and favors ones that recently
  worked. Switching to audio-only keeps Info and Queue accessible in landscape.
- **Local music and queues.** Songs become playable while Videre scans your
  library. Sort by title, artist, album, or date, rename supported files, and
  use **Play next** or **Add to queue**. You can reorder songs while one plays.
- **Listening history.** Open **Music → Library → Music history** for songs
  played from Music. Audio-only plays started in Videos stay in Video history.
- **Playback preferences.** Double-tap either edge of a portrait video to seek.
  **Settings → Video player → Remember playback speed and pitch** saves
  separate preferences for videos and Music.
- **Appearance and spoilers.** Choose **Classic purple** under **Settings →
  Appearance → Color palette**. On phones and tablets, **Settings → Browsing →
  Hide comments by default** blurs the preview until you open the comments.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60956** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
