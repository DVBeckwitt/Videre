# Videre 1.22.41 Beta 1

This beta makes Music browsing use standard Invidious features, strengthens
private transport and playback recovery, and completes local profile management.

## Music and privacy

- Music has Home, Search, and Library on phones, tablets, and TV. Search finds
  songs, channels, and public playlists through your selected Invidious instance.
- Create local playlists, add or remove songs, and resume saved playback. Saved
  songs, channels, public playlists, and phone/tablet downloads remain available.
- YouTube Music-exclusive albums, charts, moods, and new-release catalogs have
  been removed. Existing album bookmark data remains in backups.
- Video, audio, downloads, images, captions, and native playback use the instance
  proxy. Direct YouTube/Google media and artwork URLs, including redirects, are
  blocked. Music has no direct YouTube Music catalog client or fallback.
- Existing optional SponsorBlock, Return YouTube Dislike, and DeArrow services
  use their respective endpoints and settings.

## Reliability and profiles

- Recover eligible metadata and midstream failures with bounded automatic
  retries and visible feedback while preserving the saved position.
- Improve background audio recovery, audio focus handling, stale seek/progress
  rejection, captions, and phone/TV playback controls.
- Add, rename, switch, and delete local profiles from Settings, Home, or Welcome.
  An empty profile can be managed before adding a server.
- Deletion names the profile in its confirmation, protects the last profile,
  stops its active session, and retires saved authentication and background data.
  Downloaded media files stay on disk. Other profiles keep their data.
- Profile controls scroll into view with TV focus. Dialogs handle short screens,
  enlarged text, and the soft keyboard.
- NerdVPN and onion routes keep account and proxy ownership through requests,
  redirects, and playback recovery. The persistent Windows test emulator keeps
  its saved NerdVPN sign-in between sessions.

## Validation and limitations

Local checks cover formatting, static analysis, offline regressions, Android
builds, native transport tests, and release-script/signing safety. Android
acceptance exercised Invidious Music search, local playlist editing and resume,
NerdVPN playback, profile creation/renaming/deletion, and TV remote navigation.
The release workflow verifies artifact versions and the existing signing identity.
`SHA256SUMS` covers the attached APKs, bundles, and source archives.

One bounded NerdVPN PSY playback attempt returned HTTP 502. The original reported
`tV5UilNUYRY` track played successfully through NerdVPN, and playlist playback and
resume passed through the DV instance. Instance availability still affects playback.
Live onion availability, physical TV/OEM screen-off behavior, and the full Nix
live integration suite have limited coverage in this beta.

Install **app-release.apk** for the universal build, or choose your device's APK.
Android 7.0 or newer is required. Version code 60905 upgrades 1.22.40 using the
existing package and signing identity. Export a local library backup before
testing a beta, since downgrading may require reinstalling.
