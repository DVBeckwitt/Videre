# Videre 1.22.41 Beta 3

This beta changes how Videre starts eligible NerdVPN videos and resumes Android
playback.

## Changes since Beta 2

- On Android phones and tablets using NerdVPN's HTTPS instance, automatic
  startup tries a compatible combined audio/video stream first. This skips the
  signed DASH manifest request for that stream. If the stream fails, DASH is
  next in the fallback order.
- Saved DASH choices still apply. A saved resolution requires a matching
  progressive stream to qualify for automatic startup. DASH remains available
  from the player controls and for adaptive quality choices.
- Android prepares eligible online videos at the saved playback position. This
  removes the seek after preparation that could make the player buffer again.
  A seek or pause requested during startup takes effect on the current source.
- Playback continues through the selected Invidious instance's media proxy.

## Validation

Formatting, configured analysis, 2,712 offline tests and all three Android
profile builds passed. The signed-in test emulator played the same video at
360p from 00:21 on NerdVPN and DVBeckwitt, including NerdVPN's automatic and
explicit DASH paths. The saved account and preferences were restored afterward.

Startup still depends on the instance delivering enough media to begin
playback. The emulator timings cover one start per path. Full live integration,
onion availability and physical-device screen-off behavior have limited
coverage in this beta.

Install **app-release.apk** for the universal build. Android 7.0 or newer is
required. Version code 60907 upgrades Beta 2 with the existing package and
signing identity. `SHA256SUMS` lists the checksums for the release files.
