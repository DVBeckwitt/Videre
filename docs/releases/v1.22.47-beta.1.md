# Videre 1.22.47 Beta 1

This beta adds optional community AI filters, a way to fill in missing details
on imported songs, and readable RSS episode descriptions.

- **AI content filters:** Choose Off, Label matches, or Hide matches separately
  for AiSList block entries, AiSList warnings, and Flow's AI music list. Each
  rule starts off. Enabled rules use signed, automatically refreshed lists.
  Music matches uploader channels in song search and discovery. Reveal hidden
  results or allow specific channels in your profile. Saved content and manual
  filters are preserved. Automatic refresh also recovers if the device clock
  moves backward.
- **Imported songs:** Open **Music → Library → Songs → Load song details** to
  fill missing titles, uploader names, and thumbnails through your selected
  Invidious instance. Existing imports can be repaired in place. The Takeout
  import itself reads the local file. Cancelling a lookup also stops pending
  NerdVPN retries.
- **RSS descriptions:** Read episode previews and open the **Description**
  action for the saved notes, including from Downloaded episodes. Videre reads
  standard descriptions and falls back to `content:encoded` or `itunes:summary`.
  Refresh an existing feed to pick up missing notes. Deeply nested descriptions
  no longer prevent the feed from opening.

Install **app-arm64-v8a-release.apk** for most modern Android phones, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Build **60919** uses the existing package and signing identity. `SHA256SUMS`
lists the checksums for the release assets.
