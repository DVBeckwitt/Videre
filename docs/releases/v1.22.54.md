# Videre 1.22.54

- **Playback retries.** Watch, Music, and Listen can try a backup Invidious instance after the primary instance runs out of eligible retries. In **Settings → Profiles**, set **Alternate backend attempts** from zero to four and choose a **Playback backup instance**. To use an instance saved in another profile, turn on **Share instances for playback retries** in that profile first. The active profile keeps its queue and history.
- **Playback reliability.** Profiles shows successful starts and failures by instance and backend. Videre uses this history to rank eligible backends and choose a backup when **Best saved instance** is selected.
- **Subscriptions.** Choose the account that supplies follows and the subscription feed independently of the playback instance. Pending background subscription retries recheck which account is selected.
- **Music player.** Swipe down from Now Playing to minimize it and keep browsing while the song continues. Tap the mini-player to reopen it.
- **NerdVPN.** HTTP 429 stops the current attempt. Press **Retry** to make a fresh request with your saved account. Videre retries a media range once if a successful response ends before the requested byte position. The saved login can renew a rejected API key, and a temporary key lookup failure preserves the saved Music playlist already on screen.
- **Watch history and sign-in.** A temporary server outage that returns an HTML error page keeps history edits queued for retry and preserves the gateway session.

Install **app-arm64-v8a-release.apk** for most Android devices or **app-release.apk** for the universal build. Android 7.0 or later is required. Build **60972** uses the existing Videre package and signing key. **SHA256SUMS** lists the release file checksums.
