# Videre 1.22.35

This release gives Videre distinct artwork and refreshes its F-Droid listing.

- **Distinct Videre artwork.** Updated the app icon, store graphics, and Android TV banner to reflect Videre's own identity.
- **Current screenshots.** Refreshed the phone, tablet, and TV listing screenshots to show Videre's interface.
- **Android permission cleanup.** Removed an obsolete notification-listener permission inherited from a dependency. It applied only to Android versions older than Videre supports.

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This release uses the existing Videre package and signing identity, so official installations can update normally. `SHA256SUMS` accompanies the APKs, bundles, and source archives.
