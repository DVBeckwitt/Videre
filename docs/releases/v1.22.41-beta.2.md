# Videre 1.22.41 Beta 2

This beta reduces duplicate playback setup requests and improves recovery from
known Invidious Companion backend errors. It includes Beta 1's Invidious-only
Music, private transport, playback recovery and profile-management changes.

## Changes since Beta 1

- Android playback reuses an eligible static DASH manifest already fetched by
  the resolver, avoiding another download for native setup and track discovery.
  Signed URLs, audio-language tracks, quality selection and account ownership
  are preserved. Live and unrecognized manifests keep normal URL loading.
- Audio-track selection waits for the current native source to initialize,
  preserves an early language choice and ignores replaced or disposed sources.
- Structured metadata errors saying a backend is starting or blocked can use
  the existing bounded alternate-backend recovery. Server cooldowns, access
  refusals and the automatic-fallback setting remain respected.
- Invidious-only routing remains enforced. Video, audio, downloads and artwork
  have no direct YouTube/Google fallback; Music uses standard Invidious features.

## Validation and limits

Formatting, configured analysis and 2,698 offline tests passed, with four
opt-in live-service skips. All three Android profile APKs built. Native NerdVPN
acceptance verified actual playback progress, quality/audio tracks, pause,
seeking and saved authentication on the persistent signed-in emulator.

These changes remove demonstrated client overhead; they do not guarantee a
particular startup time or playback success rate. Small timing samples were
noisy, and server/companion buffering and availability still affect playback.
Live onion availability, physical TV/OEM screen-off behavior and the full Nix
live integration suite retain the coverage limits documented for Beta 1.

The release workflow verifies APK versions and the existing signing identity.
`SHA256SUMS` covers all attached APKs, bundles and source archives.

Install **app-release.apk** for the universal build, or choose your device's APK.
Android 7.0 or newer is required. Version code 60906 upgrades Beta 1 using the
existing package and signing identity. Export a local library backup before
testing a beta, since downgrading may require reinstalling.
