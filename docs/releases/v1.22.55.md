# Videre 1.22.55

For the YTDLnis check I used Llamigos. I picked audio in Videre. YTDLnis opened on Audio and saved an M4A. I used Open file in YTDLnis and played the M4A in Videre.

A song could go quiet with time still on the clock. It happened with downloaded songs as well as streams. Videre now waits for the end of the audio and reads the length from the player when it can.

I put a download on and looked up a different song. [Play next](https://github.com/DVBeckwitt/Videre/blob/v1.22.55/docs/music.md#browse-and-listen) put the online song right behind it. Add to queue is for the end of the list. A downloaded song can be removed from the queue if its file goes missing.

For the SponsorBlock edit, open [Music Downloads](https://github.com/DVBeckwitt/Videre/blob/v1.22.55/docs/music.md#local-library-and-downloads) and choose Export edited copy. It uses the saved marks for categories you have on. That makes a second file. The chooser starts on Export original.
