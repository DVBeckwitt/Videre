# Videre 1.22.55

- **Music playback.** Improved end-of-track handling so streamed and local songs can finish before playback advances. Now Playing uses the duration reported by the audio player when available.
- **Mixed Music queues.** Use **Play next** or **Add to queue** to mix streamed songs, Videre downloads, and device files. A missing queued download is marked **File unavailable** and can be removed from the queue.
- **YTDLnis downloads.** On Android, choose **Download with YTDLnis** on a supported song or video to open its YouTube link in the installed YTDLnis app. YTDLnis uses its own download and network settings.
- **SponsorBlock audio exports.** In Music Downloads, choose **Export edited copy** to save a separate audio file with saved SponsorBlock segments removed for your enabled categories. You can also export the original.

Install **app-arm64-v8a-release.apk** on most Android devices or **app-release.apk** for the universal build. Android 7.0 or later is required. Build **60973** uses the existing Videre package and signing key. **SHA256SUMS** lists the release file checksums.
