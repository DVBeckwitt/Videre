# Videre 1.22.34 Beta 1

This is an opt-in beta prerelease. The latest stable release remains v1.22.33.

## Android TV watch history

- Open **History** from the TV sidebar to find previously watched videos.
- **On this device** shows local history, progress, and completed videos. Reopening a partly watched video uses its saved position on the TV.
- When signed in, **On your server** shows history from the selected Invidious account. Use the same instance and account to find videos watched on another device. Invidious history does not include playback timestamps, so it does not provide exact cross-device resume.
- History is added to existing TV layouts while preserving their other sections. Hide it in TV layout settings if desired; phone and tablet layouts stay independent. TV layout choices are included in backups.
- Refresh, pagination, and retry controls work with the remote. An unavailable video does not block the rest of the list, and overlapping account-history pages no longer show duplicate cards.
- Returning from playback preserves focus, including when an older video moves to the top of history. The TV sidebar also handles smaller screens and its expansion animation without overflowing.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the existing Videre package and release signing identity, so official installations can update normally. Export a library backup before trying it; returning to an older stable version may require reinstalling.

Validation passed 1,081 offline tests. Android emulator checks covered D-pad navigation, local playback resume, returning from playback, account-history pagination, retry after a simulated server failure, empty history, and sign-out. Server checks used a deterministic fixture; physical TVs and live Invidious accounts were not tested. Deep-list reordering and overlapping pages have automated regression coverage.

The release workflow verifies APK versions and the existing signing identity. `SHA256SUMS` covers the attached APKs, bundles, and source archives.
