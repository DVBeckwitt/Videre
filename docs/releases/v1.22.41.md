# Videre 1.22.41

This release brings Invidious-only Music, profile management, and Android
playback improvements to the stable channel.

## Music and privacy

- Search for songs, channels, and public playlists through the selected
  Invidious instance. Save songs and channels, edit local playlists, and resume
  playback from the Music library.
- Music uses standard Invidious features. YouTube Music-exclusive catalogs
  have been removed. Existing album bookmarks are preserved in library data.
- Video and audio streams, downloads, and artwork use Invidious routes. Videre
  blocks direct requests and redirects to official YouTube media endpoints.

## Playback

- Android starts video at the saved position and applies the saved DASH quality
  before loading media. Compatible automatic playback on NerdVPN can start with
  a combined audio and video stream.
- Playback and track menus share eligible static DASH manifests, including
  manifests reached through verified redirects on the same instance.
- When a DASH media request repeatedly returns HTTP 500 during startup, Android
  can switch sooner to a compatible stream through the same instance.
- Recover eligible metadata and midstream failures with bounded retries and
  retain the saved position. Playback shows retry progress and lets you retry
  manually when recovery runs out.

## Profiles

- Add, rename, switch, and delete local profiles from Settings, Home, or
  Welcome. Profile deletion confirms the selected profile and protects the
  last one. Downloaded media files stay on disk.
- Playback recovery and Tor routes use the selected profile’s account and
  connection settings.

## Installing

Install **app-release.apk** for the universal build, or choose your device’s
APK. Android 7.0 or newer is required. Version code 60908 upgrades 1.22.40 and
the 1.22.41 betas. `SHA256SUMS` lists the checksums for the release files.

The DASH changes reduce redundant requests and speed up some recovery paths.
Successful startup times still vary with instance availability, media delivery,
and the network.
