# Videre 1.22.36

- Restored adaptive playback on NerdVPN when Videre cannot recover the signed DASH manifest. Videos with usable HD tracks can play above 360p.
- Added H.264 and AAC MP4 downloads. The quality picker now includes higher resolutions when the instance offers them in a supported MP4 format.
- Includes the updated Videre icon, Android TV banner, and F-Droid listing artwork and screenshots from 1.22.35.

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. The package and signing identity support updates from previous official GitHub builds. `SHA256SUMS` covers the APKs, bundles, and source archives.
