# Videre 1.22.43

- Sharing uses the selected Invidious instance. Supported links in descriptions
  and comments open inside Videre and use the instance address when copied or shared.
- API and playback requests reject redirects to another origin. Media referenced
  by an adaptive stream stays on the selected instance.
- Browser sign-in uses Videre's protected Android WebView. Plain HTTP
  instances can still use the account's cookie sign-in form.
- The quality picker explains how the adaptive quality limit works on Tor.
  Available qualities depend on the video and instance. If playback buffers,
  choose a lower quality. Videre keeps the selected onion address.

Install **app-release.apk** for the universal build, or choose the APK for
your device. Android 7.0 or newer is required. This release uses version code
60910. `SHA256SUMS` lists the checksums for the release files.
