# Videre 1.22.51 Beta 2

On phones and tablets, turn on **Settings → Browsing → Hide comments by default**
to avoid spoilers on a video’s watch page. The Comments card stays visible and blurs its preview.
Tap the preview to open the full comments. In layouts with tabs, select
**Comments** to read them. Videre saves the setting with your profile.

The universal APK is about **18 MB smaller** than a comparable Beta 2 build
before the size changes. All three Android architectures are still supported.
[APK size audit](https://github.com/DVBeckwitt/Videre/blob/v1.22.51-beta.2/docs/verification/size-and-loading-audit.md#local-12251-beta2-size-check-20-november-2026)

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60953** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
