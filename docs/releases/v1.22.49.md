# Videre 1.22.49

This release improves scrolling on For You and Discover, adds artist releases
to Music, and gives you more control over Now Playing.

- **Video feeds.** For You and Discover do less work while you scroll, including
  with animations off. Returning to For You keeps the previous cards visible
  while recommendations refresh. A card must stay at least halfway on screen
  for a full second to count as seen.
- **Music discovery.** Music Home shows chart tracks and releases from saved
  artists. Refresh favors chart songs you haven’t recently seen. Artist pages
  show release playlists when your selected Invidious instance supplies them.
  Open a release to browse its tracks, then use Back to return to the artist.
  Charts, artist pages, and release playlists all use the selected instance.
- **Lyrics and artwork.** Synced lyrics highlight the current line and follow
  playback. Scroll to read ahead and select **Follow lyrics** to return.
  Expanded Now Playing gives artwork more room. Under **Settings → YT Music
  → Cover corners**, choose rounded or square corners.
- **Audio quality and recovery.** Set **Streaming audio quality** to Auto,
  Data saver, or Highest available for your profile, or pick a rendition for
  the current song in Now Playing. Music can switch sooner to another eligible
  backend on the same instance when the current backend reports that it is
  blocked or starting up.
- **Closing Videre.** Swiping the app out of Android Recents stops playback
  and releases the media session.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60950** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
