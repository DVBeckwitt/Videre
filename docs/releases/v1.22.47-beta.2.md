# Videre 1.22.47 Beta 2

- **AiSList badges** on video and channel search cards identify block entries
  and warnings. Select a badge on a phone or tablet to
  view the match and allow the channel. Videre can also use a canonical
  channel link when the Invidious response omits the channel ID.
- **First-instance setup** explains AiSList and preselects **Hide matches**
  for the block list and **Label matches** for warnings. Choose either rule
  before connecting. Videre saves the choices when it accepts the instance.
  You can edit both later under **Settings → Browsing → AI content filters**.
  The separate Flow AI music rule starts off.

Install **app-arm64-v8a-release.apk** for most modern Android devices, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Build **60920** uses the existing package and signing identity. `SHA256SUMS`
lists the checksums for the release assets.
