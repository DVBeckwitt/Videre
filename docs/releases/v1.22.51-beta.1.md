# Videre 1.22.51 Beta 1

This beta improves **Music → Library → On this device** and makes it easier to
decide what plays next.

- **Local music opens sooner.** Songs become playable as Videre finds them.
  Videre saves tags and artwork so reopening an unchanged library takes less
  work. Choose a folder or grant audio permission to use Android's indexed
  music library.
- **Sort and rename.** Sort by title, artist, album, date added, or date
  modified in either direction. Videre remembers your choice. **Rename file**
  changes the filename on supported storage and keeps the embedded title.
- **Manage the queue.** Use **Play next** or **Add to queue** on a local song.
  Add the same file more than once and drag individual upcoming entries.
  The queue marks the current song and includes **Move up**, **Move down**,
  and **Remove from queue** actions.

On the Android 16 test emulator, a 503-file library showed a playable row
while indexing continued. A cached reopen read zero audio tags. The same
emulator verified switching between local audio and signed-in NerdVPN
playback. [Verification](../verification/local-music-library.md)

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60952** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
