# v1.22.30

- Removed the retired `hd720` progressive quality option while preserving adaptive 720p DASH playback.
- Clarified the DASH setting description to recommend leaving adaptive streaming enabled unless playback problems occur.
- Added a quick playback-speed slider with 0.5x, 1x, 2x, 3x, and 4x stops. Tapping the speed entry opens advanced controls with presets, reset to normal speed, and selectable fine-adjustment steps. Shared advanced controls also support TV D-pad navigation.
