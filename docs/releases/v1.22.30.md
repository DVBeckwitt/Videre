# v1.22.30

- Added Gandalf verification for HTTP onion instances through the configured SOCKS5 proxy, using Android's built-in WebView. No additional browser installation is needed, and Videre reuses the verified session.
- Kept verification cookies and browser headers scoped to the exact onion origin and proxy configuration. Off-origin requests and redirects do not receive those session headers. The local verification gateway requires a private, per-attempt token and resolves onion hostnames through SOCKS5.
- Restricted the verification browser's network access to its local gateway with a browser-enforced connection allowlist, including blocking WebRTC connections.
- Encrypted saved verification sessions with Android Keystore and excluded them from Android backups, device transfers, and Videre exports. Session cookies and verification tokens are kept out of diagnostic logs. Existing account login cookies are preserved when applying verification headers.
- Removed the retired `hd720` progressive quality option while preserving adaptive 720p DASH playback.
- Clarified the DASH setting description to recommend leaving adaptive streaming enabled unless playback problems occur.
- Added a quick playback-speed slider with 0.5x, 1x, 2x, 3x, and 4x stops. Tapping the speed entry opens advanced controls with presets, reset to normal speed, and selectable fine-adjustment steps. Shared advanced controls also support TV D-pad navigation.
