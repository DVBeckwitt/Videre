# Videre 1.22.52 Hotpatch

This hotpatch improves NerdVPN sign-in and makes it easier to find and
approve HTTPS servers that deliver video or audio for an Invidious instance.

## Find media companion hosts

A media companion is a server your Invidious instance may use to deliver
video or audio. Your chosen instance still handles search, comments, and your
account. If it sends playback to a different HTTPS address, Videre needs your
approval before it can stream from that address. If playback already works,
you can leave the list empty.

Open **Settings → Manage servers**, select the instance account, and choose
**Find media hosts** under **Media companion hosts**. Videre checks one sample
video and shows the exact addresses it finds for you to review. It tells
you if the check could not finish. Other videos may use different addresses.
Ask your instance operator for the public HTTPS address if you need to enter
one manually. For example, enter
`https://media.example.org:8443` if they give you
`https://media.example.org:8443/companion`.

Videre remembers approvals for that instance within your profile. An approved
host can see the stream request and the IP address used to connect to it.
Your sign-in credentials stay with your Invidious instance.
[Media companion guide](https://github.com/DVBeckwitt/Videre/blob/v1.22.52/README.md#media-companion-hosts)

## NerdVPN sign-in

Ordinary HTTPS NerdVPN accounts have a dedicated **Sign in to NerdVPN**
action. Sign-in errors explain connection failures, rate limits, and
temporary server outages. When NerdVPN provides a retry time, Videre shows
it and waits before reopening sign-in for the same account or setup form.
Videre also prevents automatic resubmission of a single-use sign-in code
after a temporary server error. [Issue #49](https://github.com/DVBeckwitt/Videre/issues/49)

## Read release notes offline

Open **Settings → About → Release notes** to read the notes for your installed
version or select an older release. Open a link in the notes to see and copy
its address. On TV, use **Links in this release** with the remote.

Search and playback passed on the Android 16 emulator with both an ordinary
HTTPS instance and a saved NerdVPN HTTPS account. [Android verification](https://github.com/DVBeckwitt/Videre/blob/v1.22.52/docs/verification/issue-49-sign-in.md)

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60957** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
