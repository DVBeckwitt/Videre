# Videre 1.22.33 Beta 4

This is an opt-in beta prerelease. The latest stable release remains v1.22.32.

## New in Beta 4

- **Queue autoplay control:** use **Autoplay next in queue** on the queue screen, in **Settings → Video player**, or in TV settings. It is on by default to preserve existing behavior. Turn it off to stop when each video ends, including in repeat mode. Your queue stays available and manual Next or selecting a queued video still works.
- The preference also applies to background audio and downloaded videos, survives restarts, and is included in library backups. It is separate from autoplay when first opening a video.

## Fixes and cleanup

- Completed downloaded videos now record full watched progress.
- Switching paused playback to audio no longer leaves a loading spinner over the Play button after the decoder is ready.
- Download filenames reject unsafe remote identifiers, shared links validate video identifiers, and login/link diagnostics avoid exposing cookies or raw incoming URLs.
- Consolidated download-path handling and removed an unused settings controller.

All Beta 3 features remain included, including customizable phone navigation, remembered video quality, configurable download folders, hiding watched subscription videos, and seek previews.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the existing Videre package and release signing identity. Export a library backup before trying it; returning to an older stable version may require reinstalling.

Local validation passed 1,043 offline app tests and 52 feedback-service tests. Android phone-emulator checks cover autoplay on/off, manual queue selection, preference persistence, background audio completion, and paused audio controls. Physical phones, native TV acceptance, and live Invidious integration tests are not covered by this pass. The previously documented video-card overflow with large text on very narrow screens remains outside this update.

The release workflow verifies APK versions and the existing signing identity. `SHA256SUMS` covers the attached APKs, bundles, and source archives.
