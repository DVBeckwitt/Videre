# Videre 1.22.32

This update fixes playback queues, background notifications, and several loading and download problems.

- Queue selections now change the playing video from the media notification. Shuffle no longer plays the selected item again later. Late player callbacks and missing artwork no longer disrupt playback.
- Background notifications work when first enabled. New-video counts are correct, and turning notifications off cancels pending schedule changes.
- YouTube images use the selected Invidious instance, including channel artwork, notifications, and download covers. Smaller image decodes use less memory, and TV animations avoid rebuilding their content on every frame. Instance access headers stay on their own origin when API requests redirect.
- Downloads start media transfers while artwork loads. Pause, resume, deletion, and connection changes clean up interrupted work; failed artwork does not discard valid media. Existing MP4 downloads remain playable.
- Lists recover from failed pages without losing rows or skipping results. Search and channel selectors ignore stale responses, and local subscriptions remain visible when the server fails.
- Server changes, settings, and notification records save more reliably. Deleting the selected server also updates background work. Feedback drafts keep their screenshot and retry identity.

Shared phone/TV selector code replaces the duplicate implementation, and unused helpers and obsolete code have been removed.

Checked with the repository's automated suite and an Android 16 emulator in phone, tablet, and TV layouts. Native checks include real media playback, background audio, picture-in-picture, queue controls, HTTP redirects, downloads, SQLite/file storage, Workmanager, and notification delivery. Controlled local fixtures exercise failures and races; these checks do not establish public-instance availability or physical TV behavior.

Install **app-release.apk** for the universal build, or choose the smaller APK for your device. Android 7.0 or newer is required. This release keeps the usual Videre package and signing identity. `SHA256SUMS` covers the attached APKs, bundles, and source archives.
