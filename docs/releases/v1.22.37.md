# Videre 1.22.37

This release adds NerdVPN API-key integration and includes the artwork, adaptive playback, MP4/M4A downloads, and other improvements from 1.22.36.

- **NerdVPN browser sign-in.** Token and protected sign-in use PKCE and request API-key access. Videre retrieves the key automatically when the account is eligible.
- **Clear access status.** New accounts stay saved during the instance's waiting period. Account settings show the server-provided eligibility date, disabled access, and an explicit eligibility check.
- **Secure keys and recovery.** Keys are encrypted with Android Keystore, isolated per profile/account, and sent only to NerdVPN's HTTPS origin. Key recovery preserves the login and respects gateway cooldowns.
- **Download and account fixes.** Access restrictions pause downloads while preserving partial files. Manual-key accounts can log out and clear their key; invalid key entries and storage errors show useful feedback.
- **Shared phone and TV dialogs.** Account setup uses common dialog and validation code with regression coverage for both interfaces.

Live Android checks verified sign-in, login persistence after an app update/restart, and the waiting-state flow. Successful key issuance and playback still require verification with an eligible account; the new test account remains in its waiting period.

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This release uses the existing Videre package and signing identity so official installations can update normally. `SHA256SUMS` covers the APKs, bundles, and source archives.
