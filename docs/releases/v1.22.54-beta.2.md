# Videre 1.22.54 Beta 2

- **NerdVPN playback and sign-in.** If NerdVPN returns HTTP 429 while opening a video, Videre stops that attempt. Pressing Retry sends a fresh request using your existing account. This also applies to music and downloads. The server can still ask you to wait.
- **Account recovery.** Updating clears ambiguous cooldowns saved by earlier versions. If NerdVPN rejects a key, Videre can request a replacement using the saved login. A temporary subscription or playlist outage no longer blocks video requests using a working key. Account approval dates and key-service retry times are respected.

Install **app-arm64-v8a-release.apk** for most Android devices or **app-release.apk** for the universal build. Android 7.0 or later is required. Build **60970** uses the existing Videre package and signing key. **SHA256SUMS** lists the release file checksums.
