# Videre 1.22.31 Beta 2

This is an opt-in beta prerelease. The latest stable release remains v1.22.30.

- Connect in-app bug reports and suggestions to Videre's feedback service. A GitHub account is not required. Diagnostics and screenshots remain optional, and you can review the report before sending it. Unavailable or failed submissions show a message and keep your draft for retry.
- Move **Transcript** beside the **Playback speed** button below the video. It appears when captions are available, keeping both tools together on phones and tablets.
- Make Android Back close the transcript before minimizing the player.

This update includes the playback speed, pitch, backend selection and automatic fallback features from [Beta 1](https://github.com/DVBeckwitt/Videre/releases/tag/v1.22.31-beta.1).

Install `app-release.apk` for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the normal Videre application ID and release signing identity, so it updates an existing official Videre installation. Export a library backup before trying it. Returning to an older stable version may require reinstalling; keep your backup. The separately installed test apps remain separate.

Feedback connectivity was checked from Android over valid HTTPS, and submission success/error handling is covered by automated tests using simulated responses. No real GitHub issue was submitted during these checks, so production issue creation remains unverified. Orbot feedback delivery and physical TV behavior were not tested for this update. Rapid seeking before the TV decoder is ready can still produce an initialization error. Public-instance availability varies, and a requested backend is not confirmation of the server's internal routing.

`SHA256SUMS` covers the APKs, bundles and source archives attached to this beta.
