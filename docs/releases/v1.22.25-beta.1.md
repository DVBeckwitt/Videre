Videre is an Invidious client. Connect to a public instance or your own server; no Google account is needed.

- Local playlists and Watch Later, library backups, and NewPipe subscription imports.
- Continue Watching and saved playback queues on phones and TVs.
- Download pause/resume, retry, Wi-Fi-only mode, and playlist downloads on phones and tablets.
- Send videos to Videre on your TV and control playback from your phone on the same trusted Wi-Fi.
- Pull down from the top of comments or the description to minimize. Text selection stays intact.
- Going Home opens picture-in-picture on supported Android devices. Closing the window keeps audio playing; use the notification to pause or stop.
- SponsorBlock sponsor skipping and dislike counts are on by default. Saved preferences are preserved, and dislike lookups no longer delay playback.
- Clearer Invidious setup and connection help, with playback and gesture fixes.

Install `app-release.apk` if you are unsure which APK to choose. The ARM64, ARMv7, and x86-64 APKs are smaller downloads for their respective devices. Android 7.0 or newer is required.

Promoted from the tested prerelease with the same files. 190 automated tests passed. The version still includes `beta.1` so the APKs match the tested build.

Export a library backup before updating. The earlier test APKs use a different signing key, so Android cannot update those installations with this release-signed build.

`SHA256SUMS` covers the attached APKs, bundle files, and source archives.
