# Videre 1.22.33 Beta 2

This is an opt-in beta prerelease. The latest stable release remains v1.22.32.

## New in Beta 2

- **Queue shortcut:** open the current queue from the phone's top bar, between Downloads and Playlists. The queue stays in sync with the player; you can remove, reorder, or select queued videos.
- **Remember video quality:** your selected resolution carries over to later videos and app restarts. If unavailable, Videre prefers the closest lower resolution, or the lowest available if all are higher. Turn this off in Settings → Video player or TV settings. Downloads keep their own quality selection.
- **Download folder:** choose a folder from Settings or Downloads. New downloads use it; existing downloads stay where they are. App storage remains the default. Folder permissions are device-specific and excluded from backups. Reconnect unavailable storage or choose the folder again before retrying.
- **Hide watched subscription videos:** an optional setting in Browsing and TV settings hides videos marked watched (90% played) from subscription feeds. Partly watched videos remain visible. Turn it off to show all videos again. Load more remains available when filtering hides an entire page.
- **Seek previews:** drag the phone seek bar to see a thumbnail and target time, then release to seek. TV seek controls briefly show the target preview. Thumbnails use the video's Invidious storyboard images; unavailable images fall back to the time. Live streams and offline videos have no thumbnail previews.

## Fixes and cleanup

- Keep download records when a storage provider is disconnected or cannot confirm that a file was deleted.
- Retry the failed subscription page without resetting pagination; keep watched filtering responsive to progress updates.
- Cancel an old seek gesture when the queue changes videos, so releasing cannot seek the next video accidentally.
- Reject malformed storyboard dimensions safely, handle large frame counts without integer overflow, and simplify image rendering while preserving caching and cropping.

## Included from Beta 1

Phone navigation defaults to Home, Subscriptions, History, Search. Search opens with the field focused and keyboard ready; Playlists is in the top bar. Search history is enabled by default, while an explicitly saved off setting stays off. Continue Watching and the Home Resume queue shortcut are removed. History, saved playback positions, the player queue, and Watch Later remain available. Save videos intentionally with Add to playlist → Watch Later or the player's + button.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the usual Videre package and release signing identity, so it updates an existing official installation. Export a library backup before trying it; returning to an older stable version may require reinstalling.

The offline regression suite covers the new settings, storage lifecycle, queue controls, quality selection, subscription filtering and seek previews. Android emulator checks cover phone/TV controls, watched-feed pagination, and download-provider failures. Physical removable storage, physical TVs, and live Invidious integration tests are not covered by these checks. Public-instance availability varies. The release workflow verifies APK versions and the existing signing identity.

`SHA256SUMS` covers the attached APKs, bundles, and source archives.
