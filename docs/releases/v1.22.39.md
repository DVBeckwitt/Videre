# Videre 1.22.39

Hotpatch for NerdVPN/Tor onion setup and the mini-player disappearing below the screen.

## NerdVPN onion setup

- Set up the official NerdVPN onion with **Tor Browser and an API key** on phones and TVs. Tor Browser remains a separately installed app; Videre does not bundle it. Configure Videre's SOCKS/Orbot connection separately for API requests and playback.
- Open NerdVPN preferences in Tor Browser, sign in, and enable API access when the account is eligible. Tor Browser 16 rejects links from other apps, so Videre offers **Copy address and open Tor Browser**; paste the copied address into the browser to continue.
- Closing the browser handoff dialog keeps the setup screen open, even if an earlier launch request completes late.
- Enter the API key directly in Videre. The field is obscured, keys stay encrypted and scoped to the exact account and origin, and adding the onion server requires successful authenticated API checks. Failed or cancelled setup clears its unsaved credential.
- The API-key flow is for browsing and playback; it does not sign in for remote subscription or history synchronization. Existing clearnet sign-in remains available.

## Error feedback and playback fixes

- NerdVPN setup no longer asks for a redundant local account name. Pending approval is explained consistently in settings, browsing and video loading, including when the server omits an eligibility date. A temporary refresh failure preserves the known waiting status.
- Failed sign-in connections show recovery guidance without replaying a one-use authorization code.
- The mini-player stays inside the visible screen during navigation, keyboard changes and viewport resizing. Interrupted drags settle correctly, including when the queue advances or playback switches between video and audio.

## Verification and installation

Android emulator checks confirmed the separate-browser handoff, successful sign-in to the live NerdVPN onion, and mini-player placement while playback continues. **Authenticated live onion API requests and playback still await verification with an approved API key.** The external-browser flow resolves the observed Web Crypto sign-in blocker, but account eligibility alone does not establish successful playback. TV controls have widget and D-pad regression coverage; no TV-device run was performed.

Install **app-release.apk** for the universal build, or choose the APK matching your device. Android 7.0 or newer is required.
