Videre 1.22.26 adds NerdVPN to the public server picker.

- Select **invidious.nerdvpn.de** under **Settings → Manage servers → Add server → Public instances**, then choose **Test and add server**.
- The instance remains selectable while it is listed in the official Invidious directory.

Connection checks passed for server stats, search, video metadata, direct video/audio samples, and instance-proxied video samples. Full Android playback has not been verified; public instance availability may change.

Download `app-release.apk` for any supported device, or choose the smaller APK for your device's processor.

`SHA256SUMS` covers the APKs, bundle files, and source archives.
