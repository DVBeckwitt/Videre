# Videre 1.22.47 Beta 4

- **Top charts** on Music Home opens official public Top 100 playlists for
  Worldwide and supported countries. Videre loads the playlist and its tracks
  through your selected Invidious instance.
- **Discover music** can use artists from your saved music as starting points.
  Choose an artist to load music suggestions through Invidious.

Install **app-arm64-v8a-release.apk** for most modern Android devices, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Build **60922** uses the existing package and signing identity. `SHA256SUMS`
lists the checksums for the release assets.
