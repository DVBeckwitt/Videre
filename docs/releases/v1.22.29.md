Videre 1.22.29 adds SOCKS5 support with an editable Orbot preset for Android phones, tablets, and TVs.

- Open **Settings → Network proxy**, select **Use Orbot preset**, and enable Orbot's SOCKS listener at `127.0.0.1:9050`. Orbot VPN mode is not required. Proxy settings are also available before adding your first server.
- API requests, images, native video/audio playback, and downloads use the saved proxy. When an enabled proxy is unavailable, requests fail rather than silently connecting directly. Browser sign-in follows the browser's connection; phone/TV remote control remains on the LAN.
- Changing proxy settings stops playback, cancels pending autoplay, and pauses unfinished downloads. Resume playback and downloads explicitly afterward. Saving unchanged settings keeps them running.
- Fixed cancellation races involving delayed video metadata, audio response forwarding, and TV player initialization. Cross-origin media requests do not forward instance credentials.
- Proxy settings can be changed after HTTPS playback finishes; closing idle media connections now runs off Android's main thread.

Verified with automated Dart and native transport tests and a Pixel 8 Pro running Android 17. Full-app YouTube playback and a large seek worked through Orbot using an Invidious instance with **Proxy videos** enabled; the instance selected progressive playback. Native fixtures also covered DASH/HLS decoding and seeking. Public-instance availability and Tor latency still vary; live YouTube DASH and physical TV acceptance remain unverified. See [verification details](https://github.com/DVBeckwitt/Videre/blob/v1.22.29/docs/socks-proxy.md).

Existing Videre installations retain their local data when updated with the signed APK. The proxy defaults to disabled.

Release verification accepts both current and older Android SDK signer-output formats while requiring the existing Videre signing certificate. The earlier v1.22.28 tag did not publish APKs.
