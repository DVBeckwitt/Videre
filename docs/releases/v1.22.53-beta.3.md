# Videre 1.22.53 Beta 3

- **Lyrics.** Music can try a song and artist search when the exact LRCLIB
  lookup misses. It checks the recording and can show plain lyrics when the
  timing cannot be verified.
- **Public instances.** Choose ChocolateMoo alongside NerdVPN and DVBeckwitt.
  ChocolateMoo offers six rotating playback hosts for individual approval.
- **ChocolateMoo backends.** Videre requests fresh video details from the
  selected backend and can try other backends after eligible playback failures.
  ChocolateMoo chooses the host that delivers the stream. Downloads that
  redirect to a separate media host are blocked by the download policy.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60966** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
