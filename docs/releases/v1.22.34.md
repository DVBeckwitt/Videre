# Videre 1.22.34

This release adds separate profiles, manual watched status with server sync, protected-server sign-in, and Android TV watch history.

- **Separate libraries for each person.** Open **Profiles** to create, rename, or switch people. Each person has their own history, Watch Later, playlists, subscriptions, accounts, queue, downloads, and preferences. Your existing library stays in **Default**. Multiple accounts can use the same server address. Proxy settings, certificate policy, download location, and TV mode remain device settings.
- **Mark videos watched or unwatched.** Use the video actions on phone or TV. Changes appear immediately and sync to the signed-in account's Invidious history. Pending changes survive restarts, and account settings show retry or sign-in status. Marking watched preserves the saved playback position; marking unwatched resets it. Server history does not provide exact cross-device resume positions.
- **Sign in to protected servers.** For an HTTPS instance behind Authentik, choose **Sign in to protected server**, complete gateway login, then authorize Invidious. Each account has an isolated browser cookie session. Requests to external media origins do not receive the gateway's cookies. A compatible Android System WebView with isolated-profile support is required; proxy-enabled sign-in also requires WebView proxy-override support.
- **Browse history on Android TV.** Open **History** in the sidebar for local playback history or the selected account's server history. Refresh, pagination, and retry work with the remote. Returning from playback restores focus. TV layout preferences remain independent of phone navigation.

Profile switching stops playback, clears Android's previous media title and controls, pauses downloads, and restores the selected person's library. TV focus and unsupported-download retry handling have also been improved. Manual watched choices are included in library backups; account credentials, gateway cookies, and pending server operations are excluded.

Pending watched updates respect later server-history deletion. Download resumes and account edits require the original account identity, even when another login uses the same address. Profile transitions also retire notifications from the previous person and preserve the app's version information in About.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This release uses the existing Videre package and signing identity, so official installations can update normally. Export a library backup before updating; returning to an older version may require reinstalling.

Automated coverage includes profile migration and isolation, account identity, authentication and redirect boundaries, server-history retry ordering, download ownership, worker notifications, and phone/TV regressions. Android emulator checks used local fixtures for profile switching, watched updates, downloads, browser sign-in, cookie persistence, and protected native playback. Real Authentik deployments, MFA policies, and physical TV models were not tested. See [implementation details and limitations](https://github.com/DVBeckwitt/Videre/blob/v1.22.34/docs/profiles-and-authentication.md).

The release workflow verifies APK versions and the existing signing certificate. `SHA256SUMS` covers the attached APKs, bundles, and source archives.
