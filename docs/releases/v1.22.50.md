# Videre 1.22.50

This update fixes regressions in recommendations, Music browsing, and closing
Videre from Android Recents.

- **Video recommendations.** For You resumes counting new views of its cards
  after you reset recommendations from Your Feeds.
- **Music browsing.** The chart shelf updates when you hide or allow tracks.
  Artist releases keep the rows already loaded and wait until the selected
  Invidious instance's **Retry-After** deadline before retrying.
- **Podcasts.** Swiping Videre out of Recents cancels a pending episode even
  during a handoff between screens. The current episode's progress is saved.
- **NerdVPN and local remote control.** NerdVPN key requests and playback
  recovery honor retry deadlines sent as HTTP dates. Local TV remote pairing
  stays on the local network when a process proxy is configured.

Videre loads YouTube content through the selected Invidious instance. The app
blocks direct YouTube catalog, media, and artwork destinations.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60951** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
