# Videre 1.22.46 Beta 1

This beta reduces APK size and improves library loading, search refreshes, and
download handling.

## Changes

- Replaced the full FFmpeg package with the smaller build needed for downloaded
  media, removed unused plugins, and excluded a dependency's test image from
  release APKs. Local universal-APK comparisons measured a **23.3% reduction**;
  download sizes vary by architecture.
- Large Music libraries build rows as needed and preserve keyboard/remote focus
  when earlier items are removed.
- Repeated browse requests share in-flight work. Search results refresh when
  filters change without reloading on unrelated rebuilds. Late responses cannot
  repopulate an old account's cache.
- Download cancellation waits for its own native FFmpeg operation before cleanup,
  including cancellation while the operation is queued.
- Download size estimates include the selected audio track and update when its
  language or container changes. Unknown sizes are left unspecified.
- The DASH setting now explains that it enables adaptive streaming and higher
  video qualities when available.

## Validation and beta limits

Local validation passed **3,006 offline tests**, formatting, configured analysis,
and a fresh release-mode APK build. Strict analysis is clean; the application's
existing nonfatal analysis diagnostics remain.

On the preserved signed-in Android test emulator, a NerdVPN download completed
and produced a fully decodable file. Offline playback with networking disabled,
forward/backward seeking with DASH enabled and disabled, and screen-off audio
with notification pause/resume passed. These checks cover the exercised emulator
paths, not every device or server. Earlier intermittent source failures did not
recur in these follow-up checks, and their underlying cause remains unproven.

The full live Invidious integration suite and physical phone/TV acceptance were
not run. See [the verification report](https://github.com/DVBeckwitt/Videre/blob/v1.22.46-beta.1/docs/verification/size-and-loading-audit.md)
for the measurements, regression coverage, and remaining limitations.

Install **app-arm64-v8a-release.apk** for most modern Android phones, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Version code **60916** uses the existing package and signing identity.
`SHA256SUMS` lists the release-file checksums. This is a prerelease; the stable
release remains available separately.
