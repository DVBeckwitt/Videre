# Videre 1.22.40

This release adds saved playlist progress and improves playback controls, Music
proxy handling, and recovery from interrupted requests.

## Playlists and progress

- Bookmark public playlists and resume a playlist at its saved item and exact
  timestamp. Repeated recordings keep their individual place in the queue.
- Track watch progress consistently across video cards, Music and playlists.
  Marking a video watched preserves its saved timestamp.
- Keep playlist bookmarks and progress separate for each Videre profile and
  account. Backup merge and replace preserve those boundaries.
- Load saved private-playlist artwork through its original account, including
  when another server is selected. A missing owner never falls back to another
  account for those images.
- Continue loading large playlists safely, with retry feedback when a page
  fails. Switching profiles or starting another playlist discards stale results.

## Playback fixes

- Holding the side of the video reaches 2× speed sooner, and releasing restores
  the selected speed immediately. Center playback buttons retain their normal
  touch behavior.
- Android applies temporary speed changes through the native audio track to
  reduce the extra delay from queued audio.
- Tapping the mini-player thumbnail restores the expanded player while playback
  continues. Normal drag-to-minimize and fullscreen adjustment gestures coexist.
- Audio resumes with its playlist context, and subtitle failures no longer
  interrupt otherwise playable media.

## Proxy handling and cleanup

- Music refreshes its catalog configuration when the network proxy changes and
  rejects responses and continuations from the old route.
- Music handles the anonymous consent redirect with one bounded retry and
  explains the observed region-unavailable response. Requests through SOCKS have
  a longer catalog deadline and do not fall back to a direct connection.
- Native artwork uses the shared transport. A narrowly scoped retry recovers
  eligible reads when the server closes before sending response headers.
- Removed unused store graphics, duplicate screenshots and vendored documentation
  assets, while retaining runtime assets and tests.

## Verification and known limits

The final local validation passed 2,088 offline tests, formatting and configured
analysis checks. Android emulator acceptance covered playlist resume and queue
behavior, mini-player restoration, and the faster 2× hold/release controls.
Physical-device audio latency and audible pitch still need broader verification.

**Tor routing support does not guarantee service availability.** Earlier live
tests established Music catalog access and NerdVPN onion playback through Tor.
The latest bounded rerun received Music's region-unavailable page on both tested
US and German routes. NerdVPN's public HTTPS API accepted the supplied key on
the US route, but onion connections failed and setup on the German route timed
out. Fresh end-to-end Music playback through Tor remains unverified. See the
[Music network details](../music.md#network-boundary) and
[NerdVPN verification notes](../profiles-and-authentication.md#nerdvpn-api-access).

Install **app-release.apk** for the universal build, or choose the APK matching
your device. Android 7.0 or newer is required. Version code 60904 updates 1.22.39
with the existing package and signing identity. The release workflow verifies
APK versions and signing certificates; `SHA256SUMS` covers the attached APKs,
bundles and source archives.
