# Videre 1.22.46 Beta 2

This beta adds local Takeout music import and RSS podcasts, with fixes from the
sign-in and playback regression pass.

## Changes

- Import liked songs and playlists from a local Google Takeout ZIP or CSV into
  the current profile's Music library. Import reads only the selected file;
  it does not contact Google or YouTube. Takeout contains library metadata,
  not downloaded audio.
- Add podcasts by RSS feed link. Subscriptions stay local; episodes support
  background audio, seeking, playback speed, and offline downloads.
- Podcast listening positions survive app restarts and are shared between
  streamed and downloaded copies. Progress is separate for each local profile.
- Repair temporary sign-in browser cleanup that could turn cancellation or
  authorization into a protected-session error. Existing saved credentials are
  preserved.
- Offer manual NerdVPN API-key setup for its HTTPS address as well as its onion
  address. This provides browsing/playback access when a browser challenge
  prevents sign-in; it does not sign into server history or subscriptions.
- Prevent a delayed Takeout file-picker result from closing the underlying
  screen after the import dialog has been dismissed.
- Remove Nadeko from curated suggestions after reproducing its disabled media
  proxy. Existing entries and custom addresses remain supported by the UI.

## Instance and beta limits

Validation passed: 3,163 regression tests, 136 native JVM tests, 32 isolated
Android device tests, and the release-helper, signing, and feedback-service
checks. Android emulator checks covered saved-account playback and sign-in
cancellation, local Takeout import, and podcast offline/background resume.
Optional live-service tests were skipped. Details are in the repository's
`docs/verification/v1.22.46-beta.2.md`.

Nadeko currently returns HTTP 403 with `Endpoint disabled` for the tested
proxied audio/video streams. This server-side restriction is not repaired by
this beta. Videre continues to require instance-proxied playback.

NerdVPN may require JavaScript for its browser challenge. Videre's protected
browser keeps scripts disabled; the API-key option provides a separate setup
path without weakening that protection.

Fresh valid-credential browser sign-in and clearnet manual-key setup have not
yet been verified end to end. Saved-account playback and temporary browser
cleanup have separate automated and Android emulator coverage.

Podcast subscriptions and listening positions are local to the device and are
not yet included in backup exports. Abrupt process termination can lose the
last few seconds of podcast progress. Physical phone/TV coverage and the full
live Invidious integration suite remain outside this beta's local checks.

Install **app-arm64-v8a-release.apk** for most modern Android phones, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Version code **60917** uses the existing package and signing identity.
`SHA256SUMS` lists release-file checksums. This is a prerelease; the stable
release remains available separately.
