# Videre 1.22.33 Beta 1

This is an opt-in beta prerelease. The latest stable release remains v1.22.32.

- On phones, Search moves to the bottom navigation and opens with the search field focused and the keyboard ready. The default order is Home, Subscriptions, History, Search.
- Playlists moves to the phone's top bar beside Downloads. Open it to find Watch Later and your other playlists. Tablet navigation keeps its existing layout.
- Search history is enabled by default. An explicitly saved off setting stays off; change it in Settings → Browsing → Search history.
- Remove Continue Watching and the Home Resume queue shortcut on phones, tablets, and TV. History, remembered playback positions, the player's queue, and Watch Later remain available. To save a video intentionally, choose Add to playlist → Watch Later from its menu, or use the player's + button.
- Fix saved startup-tab selection, including History after moving Playlists out of the phone's bottom navigation. A saved Playlists startup choice falls back to Home on phones; Playlists remains accessible in the top bar. The phone layout editor now matches the new navigation and preserves startup choices when reordering sections.

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the usual Videre package and release signing identity, so it updates an existing official installation. Export a library backup before trying it; returning to an older stable version may require reinstalling.

The repository's offline regression suite covers navigation, search focus and history preferences, playback queues, local library storage, and downloads. Phone, tablet, and TV layout acceptance is checked on an Android emulator; physical TV and live Invidious integration tests are not covered by this release check. Public-instance availability varies.

`SHA256SUMS` covers the attached APKs, bundles, and source archives.
