# Videre 1.22.31 Beta 1

This is an opt-in beta prerelease. The latest stable release remains v1.22.30.

- Find advanced speed controls through the clear **Advanced** button or the speed shortcut beside Repeat. New videos return to 1× unless you enable Remember playback speed.
- Adjust pitch independently from speed, from −12 to +12 semitones. Pitch resets for each new video and stays selected when switching between video and background audio for the same video.
- Choose an advertised backend on compatible Invidious instances, including NerdVPN, Nadeko, ChocolateMoo53 and MintingCup. Optional automatic fallback tries available alternatives, with progress and success/failure messages and a backend picker in the player. Support depends on the instance's advertised selector; it does not guarantee that every backend is available.
- Discover compatible backend lists while using Orbot/SOCKS5.
- Open YouTube watch and short links correctly in the TV interface, including when starting Videre from a closed state.
- Fix a playback-resume race when returning from background audio to video.
- Prepare bug reports and suggestions in Settings, with optional diagnostics and screenshots. Unavailable or failed submissions show a message and retain the report for retry.

**In-app issue submission is not activated in this beta.** This build is not connected to a feedback relay, so the app explains that sending is unavailable and keeps Send disabled. You can save a draft or report directly through [GitHub Issues](https://github.com/DVBeckwitt/Videre/issues). Local and Render hosting preparation is included in the source; no GitHub credentials are embedded in the app.

Install `app-release.apk` for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the normal Videre application ID and release signing identity, so it updates an existing official Videre installation. Export a library backup before trying it. Returning to an older stable version may require reinstalling; keep your backup. The separately installed **Videre Test** app remains separate.

Known testing limits: TV navigation and controls have been checked in an Android emulator; physical TV validation is still needed. Rapid seeking before the TV decoder is ready can still produce an initialization error. Public-instance availability varies, and a requested backend is not confirmation of the server's internal routing.

`SHA256SUMS` covers the APKs, bundles and source archives attached to this beta.
