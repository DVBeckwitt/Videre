# Videre 1.22.46 — NerdVPN hotfix

NerdVPN sign-in updates for [issue #38](https://github.com/DVBeckwitt/Videre/issues/38),
plus local Music import, RSS podcasts, and playback fixes.

- **NerdVPN sign-in:** use **Sign in with browser** for its HTTPS address when
  Videre's network proxy is off. Android's default browser opens the sign-in page
  and returns to Videre after authorization. **Sign in in app** also allows
  JavaScript for a temporary session restricted to NerdVPN's HTTPS origin.
  SOCKS and onion connections keep
  their configured routing. Failed or cancelled attempts preserve saved logins;
  manual API-key setup is also available.
- **Music import:** import liked songs and playlists from a local Google Takeout
  ZIP or CSV. This imports library entries, not audio files, without contacting
  Google or YouTube.
- **RSS podcasts:** add feed links, listen in the background, change playback
  speed, and download episodes. Listening positions survive restarts and work
  across streamed and downloaded copies within each local profile.
- **Playback and navigation:** fix delayed Stop, Pause, seek, and speed changes,
  plus import dialogs covered or dismissed during loading. Enabling Wi-Fi-only
  downloads now stops an active podcast transfer on cellular data.
- **Size and loading:** reduce APK size, load large Music libraries as needed,
  and avoid duplicate browsing requests. Correct download size estimates and
  cancellation, and explain higher-quality playback in the DASH setting.
- **Server errors:** show a clear error for incomplete video details. Nadeko
  playback remains unavailable because its operator disables third-party API
  access; current media requests return `403 Endpoint disabled`. It was removed
  from curated suggestions; existing saved entries remain available.

Install **app-arm64-v8a-release.apk** for most modern Android phones, or
**app-release.apk** for the universal build. Android 7.0 or newer is required.
Version code **60918** uses the existing package and signing identity.
`SHA256SUMS` lists the release-file checksums.
