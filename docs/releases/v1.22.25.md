Videre 1.22.25 improves playback controls and makes connecting to an Invidious server easier.

- Fixed dropped play and pause commands in picture-in-picture and notifications.
- Fixed background Stop and kept the playback position when switching between video and audio.
- Improved search editing, comment replies, and retry controls.
- Added F5 and Nadeko to the public server picker, with saved server switching and custom addresses.
- Reduced duplicate requests and added clearer connection checks with an option to open videos in a browser.

268 automated tests passed. Public host checks covered search, video data, and media access. Availability can change.

Download `app-release.apk` for any supported device, or choose the smaller APK for your device's processor. This release uses the same signing key as the previous public release and the recent test builds.

`SHA256SUMS` covers the APKs, bundle files, and source archives.
