# Videre 1.22.48 Beta 2

**Music navigation.** Tap a linked artist in Now Playing to open their Music
page while the song keeps playing. The bottom Search button now opens Music
Search from Music and video search from video tabs. Returning to Music Search
keeps your query.

**Song menus.** Open the three-dot menu on a Quick Pick or ranked discovery
song to find Play next, Add to queue, Save, and recommendation feedback in one
place. Long-press opens the same actions. The two groups sit side by side on
wider screens.

**Playlist copies.** Save a copy on server now keeps working when Music
redraws the playlist. If Invidious returns HTTP 500 while adding a song, Videre
checks which tracks reached the server before resuming once. If a track still
fails, the app shows its name and position and offers **Resume server copy**.
If you deleted the previous server copy, you can confirm a replacement.

**Downloaded music.** Imported songs can keep the title and artist link
returned by Invidious when downloaded. Quick Picks can also recover a known
artist link for an older download from the active profile.

**Install.** Download **app-arm64-v8a-release.apk** for a modern ARM64 phone
or **app-release.apk** for the universal build. This beta requires Android
7.0 or later and uses Videre’s existing signing key and package. Its version
code is **60948**. File checksums are in **SHA256SUMS**.
