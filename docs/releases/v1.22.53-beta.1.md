# Videre 1.22.53 Beta 1

- **Music Search and discovery.** Filter results by songs, albums, artists, or
  playlists. Search within an artist’s catalog, choose between verified artist
  matches when available, and use optional voice search.
- **Device music.** Browse local folders and Videre downloads together. Hide
  unwanted recordings, fast-scroll artist and genre indexes, sort songs, and
  queue an entire artist or genre. Tablets can browse collections in two panes.
- **Playlists and library.** Select multiple songs, rearrange library categories,
  organize playlists into folders, restore playlists, and choose a path format
  for M3U export.
- **Now Playing.** Open Queue, Sleep, and Lyrics from the pinned footer. Show
  synced lyrics or artwork backgrounds and adjust playback speed and pitch.
- **Music playback.** Sort upcoming tracks, start radio without interrupting the
  current song, Like from the mini-player or Android media controls, and choose
  whether Music remembers its queue after a restart.
- **Watch playback.** Lock fullscreen touch controls, pinch to zoom, skip
  chapters, and preview adjacent frames while seeking. The wide floating
  player adds ten-second skips and a cancellable autoplay countdown.
- **Watch browsing.** Video Home keeps visible recommendations steady, and
  timestamped comments can follow playback.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60964** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
