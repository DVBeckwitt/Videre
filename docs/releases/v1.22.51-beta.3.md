# Videre 1.22.51 Beta 3

- **Music downloads.** The format picker labels Opus as **Opus (Best quality)**.
  Opus preserves the original quality of an Opus source. M4A preserves the original
  quality of an AAC source.
- **Playback speed and pitch.** Turn on **Settings → Video player → Remember
  playback speed and pitch** to save separate values for videos and Music.
- **Music queue.** Drag songs above or below the currently playing track, or use
  **Move up** and **Move down**. The current song keeps playing while you reorder.
- **Portrait video gestures.** Double-tap the left or right edge of the video to
  seek. Finishing or canceling a feedback screenshot returns you to your report draft.

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60954** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
