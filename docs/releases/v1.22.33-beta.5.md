# Videre 1.22.33 Beta 5

This is an opt-in beta prerelease. The latest stable release remains v1.22.32.

## New in Beta 5

- **Animation controls:** choose **Follow system**, **Reduced**, or **Off** in **Settings → Appearance → Animations** on phones and tablets, or in TV settings. Follow system is the default.
- Reduced removes interface movement and decorative pulsing while keeping brief fades. Off also stops loading animations; loading indicators and real progress updates remain visible.
- Android's **Remove animations** setting always takes precedence. Your preference survives restarts and is included in library backups.
- Navigation, dialogs, scrolling, thumbnails, and player controls follow the preference while playback, gesture timing, and notification timeouts retain their behavior.

## Fixes and cleanup

- Sponsor-skip and sleep-timer feedback remain visible long enough to read with reduced or disabled animations.
- Switching animation settings preserves active routes, text input, and TV focus feedback.
- Consolidated fade handling, removed a redundant animation dependency and unused playlist scrolling code, and reused Flutter's built-in overscroll configuration.

All Beta 4 features remain included, including queue autoplay controls, customizable phone navigation, remembered video quality, configurable download folders, hiding watched subscription videos, and seek previews.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the existing Videre package and release signing identity. Export a library backup before trying it; returning to an older stable version may require reinstalling.

Local validation passed 1,063 offline app tests. Android emulator checks cover the animation choices, persistence, Android's animation override, phone playback and pause, notice timing, and TV D-pad navigation and seeking. Physical devices and live Invidious integration tests are not covered by this pass. The previously documented video-card overflow with large text on very narrow screens remains outside this update.

The release workflow verifies APK versions and the existing signing identity. `SHA256SUMS` covers the attached APKs, bundles, and source archives.
