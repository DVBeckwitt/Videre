# Videre 1.22.51 Beta 4

- **Audio-only playback.** Switching a video to audio-only keeps the controls,
  Info and Queue accessible in portrait and landscape, including with large text.
  Stopping fullscreen playback restores the previous screen and the system bars.
- **Backend recovery.** When automatic fallback is enabled, playback and
  downloads can try up to two other backends on the same account. Videre
  favors backends that recently worked and respects the server’s retry time.
- **Music and Video history.** Find listening history under **Music → Library
  → Music history**. Audio-only plays started in Videos stay in **Video history**.
  Removing a recording from one section preserves its entry in the other and
  its resume position. Earlier entries remain under **All history on this device**.
- **Classic purple.** Choose **Settings → Appearance → Color palette → Classic
  purple** to use the original colors throughout Videre, including the Music player.

On Android, selecting a previously played download from History reopened the
saved file on both phone and TV layouts without contacting the test server.
[Android verification](https://github.com/DVBeckwitt/Videre/blob/v1.22.51-beta.4/docs/verification/issues-45-47.md)

Install **app-arm64-v8a-release.apk** for most modern Android devices or
**app-release.apk** for the universal build. Android 7.0 or later is required.
Build **60955** uses the existing Videre package and signing key.
**SHA256SUMS** lists the release file checksums.
