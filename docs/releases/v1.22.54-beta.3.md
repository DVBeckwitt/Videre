# Videre 1.22.54 Beta 3

- **Playback.** If NerdVPN returns HTTP 200 but the response ends before the requested byte position, Videre retries that same media range once. A 429 still stops the attempt until you press Retry.
- **Saved Music playlists.** A temporary NerdVPN key lookup failure preserves the playlist already loaded for that account.
- **Watch history and sign-in.** A temporary server outage that returns an HTML error page keeps history edits queued for retry and preserves the gateway session.

Install **app-arm64-v8a-release.apk** for most Android devices or **app-release.apk** for the universal build. Android 7.0 or later is required. Build **60971** uses the existing Videre package and signing key. **SHA256SUMS** lists the release file checksums.
