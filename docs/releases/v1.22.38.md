# Videre 1.22.38

This release brings the Music experience from the 1.22.38 betas to stable, with artwork, playback, subtitle and server-access fixes from two additional regression passes.

## Music

- Switch between **Videos** and **Music** in the top bar. Music has Home, Explore and Library, with public releases, country charts, moods and genres, and song, album, artist and playlist search. No Google account is required.
- Save songs and collections in your Videre profile, use local playlists, and download audio on phones and tablets. Music shares Videre's playback queue, background audio and saved-session resume. Choose Videos only or Music only in **Settings → Browsing → Home experience** to hide the switch.
- Catalog covers load directly through the configured network transport. Saved songs, playlists and History preserve Music artwork and metadata, including authenticated Invidious fallback thumbnails. History reopens songs as Music, and older queued downloads retain authenticated fallback artwork. Older library backups remain importable and keep supported relative image routes.
- Catalog browsing comes from YouTube Music. Audio playback and downloads use your selected Invidious backend; media-proxy settings determine whether the instance also proxies the audio. Availability still depends on those services.
- Paid sponsorship and Music: Non-Music Section skipping are enabled by default while preserving explicit opt-outs. New Music downloads cache available enabled SponsorBlock segments for offline use. Skipping depends on community coverage.

## Playback and captions

- Fullscreen video uses the complete viewport, with controls inside safe screen insets and a safe aspect ratio when decoder dimensions are missing. Touch controls work in letterbox areas, and compact video cards show duration badges.
- Hold the video to play at 2× and release to restore the selected speed. Stream reloads and rejected decoder requests clear the temporary speed indicator.
- Caption failures offer Retry and Close without covering the seek bar or replacing a working caption track. Malformed timing is rejected, valid single-cue SRT files load, and a delayed stream manifest cannot reset the user's caption selection.
- Available dislike counts, including zero, use the shared Return YouTube Dislike settings.

## Server access and compatibility

- NerdVPN's official onion address supports API-key sign-in through the configured SOCKS/Orbot connection. Keys stay separate for each account and exact origin. HTTP onion sign-in requires SOCKS and stays scoped to the selected origin; HTTPS retains certificate validation.
- Advanced server setup accepts usable relative thumbnail URLs. Delayed authentication responses cannot apply an old cooldown after the user's key intent changes.
- Testing an unsaved proxy leaves the saved account's cookies and access state intact. Changing proxy settings cancels pending sign-in before a browser can open with the old connection policy.
- Profile isolation, Music navigation and Back behavior, large-text layouts, queue identity and library-backup compatibility include regression fixes from the betas.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the APK matching your device. Android 7.0 or newer is required. Version code 60902 is newer than both 1.22.38 betas and uses the existing Videre package and signing identity.

Validation covers repository formatting and analysis, offline regressions, live anonymous Music checks, native proxy tests, release-script safety and APK-signing checks, Android builds and emulator acceptance. Physical Android devices/TVs and the full nix-shell live Invidious suite were not tested. Google-account synchronization and gapless playback remain outside this release.

The release workflow verifies APK version numbers and the existing signing certificate. `SHA256SUMS` covers the attached APKs, bundles and source archives.
