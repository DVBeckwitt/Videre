# Videre 1.22.38 Beta 1

This is an opt-in beta prerelease. The latest stable release remains v1.22.37.

## Music

- Browse songs, albums, artists and public playlists without a Google account. Open **More shortcuts → Music** on phones, or the Music button on tablets and TVs.
- Play Music through Videre's existing Invidious playback engine, with artwork, queues, shuffle, repeat, speed controls, background audio and session resume.
- Save songs and collections to local playlists and download Music for offline playback. Catalog labels survive saved-playlist downloads and library backup/restore.
- Music artist links support both `/browse/UC…` and `/channel/UC…`. Album playlists with an unavailable first track can still load their playable songs.

## SponsorBlock and playback fixes

- **Paid sponsor segments and Music: Non-Music Section are skipped by default.** Existing explicit off preferences are preserved. Adjust categories in **Settings → Video player → SponsorBlock**; changes apply when a track is loaded again.
- SponsorBlock keeps precise timestamps, combines overlapping sections and avoids cutting extra audio. Music displays a brief skip notice on phones, tablets and TVs.
- New Music downloads cache available SponsorBlock sections for the categories enabled at download time. Existing downloads need downloading again to acquire missing segment data. Skipping depends on community coverage and service availability.
- Caption loading failures provide retry/dismiss feedback without breaking playback or discarding a working caption selection. Return YouTube Dislike now uses the shared settings and correctly displays available counts, including zero.
- Queue occurrence identity, profile isolation, interruption handling and saved playback positions have regression coverage across Music and ordinary video playback.

## Installation and verification

Install **app-release.apk** for the universal build, or choose the smaller APK matching your device. Android 7.0 or newer is required. This beta uses the existing Videre package and release signing identity. Export a library backup before trying it; returning to an older stable version may require reinstalling.

Validation includes the canonical formatting, analysis and offline regression checks, the live anonymous Music catalog smoke test, Android builds and emulator checks. Physical Android phones/TVs and the full nix-shell live Invidious suite have not been tested for this beta. Google-account library synchronization and gapless playback are outside this release.

The release workflow verifies APK version numbers and signing identity. `SHA256SUMS` covers the attached APKs, bundles and source archives.
