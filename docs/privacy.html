Videre privacy policy

Videre does not collect user data during normal app use. User accounts are linked to the Invidious instance the user chooses, whether it is self-hosted or operated by a third party. The developers of Videre do not provide public Invidious servers.

Opening Public instances contacts api.invidious.io to load the official directory without sending saved server credentials. Selecting a suggestion fills the address; the chosen server is contacted when you test or use it. Public server operators have their own privacy policies.

Bug reports and suggestions are sent only when you choose Send after reviewing the report. The feedback service creates a public issue in the Videre GitHub repository on your behalf; a GitHub account is not required. The title, description, and any attachments you choose become public. Do not include passwords or other private information in your text or screenshot.

Diagnostics and screenshots are optional and off by default. Diagnostics use a limited list of app and Android versions, device model, playback mode, proxy enabled status, and backend recovery state. They exclude saved login cookies, authorization headers, server addresses, video IDs, watch history, and raw application logs. A selected screenshot is sent to the feedback service and hosted there for display in the public issue, without uploading it to Imgur.

Drafts and recent submission receipts are stored in the app. There is no background submission. The feedback service stores submission records to prevent duplicate issues and uses short-lived, hashed network-address information and request limits to reduce spam. As with any network service, its host receives connection information; app feedback follows the configured SOCKS5/Orbot routing policy. Public GitHub issues and their attachments may be copied or cached by others.

Videre developers do not own, collect, or share user data outside user-initiated feedback.
